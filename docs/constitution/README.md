# Holacracy-Verfassung 5.0

`Holacracy-Verfassung.md` is the official German translation of the
Holacracy Constitution 5.0 by HolacracyOne, unchanged, from
<https://github.com/holacracyone/Holacracy-Constitution-5.0-GERMAN>,
licensed under CC BY-SA 4.0 (`LIZENZ.md`).

The core roles' purposes, accountabilities and domains in
`governance/roles/constitution.py` follow the texts GlassFrog shows for the
constitution 5.0.
