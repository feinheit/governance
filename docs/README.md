# Help

This tool records how we're organized: circles and roles with purpose,
accountabilities, domains and policies, who holds which role, and how
that has changed since 2018. Changes go through proposals, async or in a
governance meeting, as the
[Holacracy Constitution 5.0](constitution/Holacracy-Constitution.md)
provides ("Deutsch" next to its title shows its German translation). This help explains
the tool, not Holacracy.

- [Finding your way](orientation.md): circles, roles, people, search,
  history, mails
- [Proposals](proposals.md): drafting, publishing async,
  responding
- [Meetings](meetings.md): governance and tactical meetings, elections
- [Operational work](operational.md): what changes without a proposal
- [Mails](mails.md): when the tool sends mails and to whom

## What the tool doesn't do

- **Projects and actions** stay in the task management tool. Roles and
  circles link there, tactical meetings record the link to the task
  created.
- **Scheduling**: you plan meetings in the calendar. In the tool a meeting
  begins when somebody starts it.
- **Elections** are run by the facilitator in the meeting, the tool only
  records the result.
- **Agreements between people**: relationship agreements, asking for
  permission to impact a domain, announcing spending or explaining
  individual action happen in the chat or in the task management tool.
- **Linked roles** (1.3.4) and passing on references from outside the
  circle (1.4.4) don't exist.
- **The core roles** (Circle Lead, Facilitator, Secretary, Circle Rep)
  stay as the constitution defines them: governance doesn't add
  accountabilities or domains to them.
- **Mails** can't be unsubscribed one by one, only extended to all
  circles. Filter them in your mail program.
