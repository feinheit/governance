# Hilfe

Governance hält fest, wie wir organisiert sind: Kreise und Rollen mit
Purpose, Accountabilities, Domains und Policies, wer welche Rolle hat, und
wie sich das seit 2018 verändert hat. Änderungen laufen über Vorschläge,
asynchron oder im Governance Meeting, wie es die
[Holacracy-Verfassung 5.0](constitution/Holacracy-Verfassung.md)
vorsieht. Diese Hilfe erklärt das Tool, nicht Holacracy.

- [Sich zurechtfinden](orientierung.md): Kreise, Rollen, Personen, Suche,
  Geschichte, Mails
- [Spannungen und Vorschläge](vorschlaege.md): entwerfen, asynchron
  veröffentlichen, antworten
- [Meetings](meetings.md): Governance und Tactical Meetings, Wahlen
- [Operative Arbeit](operatives.md): was ohne Governance geändert wird

## Was das Tool nicht macht

- **Projekte und Aktionen** bleiben im Aufgaben-Tool. Rollen und Kreise
  verlinken dorthin, Tactical Meetings halten den Link zur erstellten
  Aufgabe fest.
- **Termine**: Meetings plant ihr im Kalender. Im Tool beginnt ein Meeting,
  wenn jemand es startet.
- **Wahlen** führt der Facilitator im Meeting durch, das Tool hält nur das
  Ergebnis fest.
- **Absprachen zwischen Personen**: Beziehungsvereinbarungen, um Erlaubnis
  für eine Domain fragen, Ausgaben ankündigen oder individuelle Initiative
  erklären geschieht im Chat oder im Aufgaben-Tool.
- **Linked Roles** (1.3.4) und das Weiterleiten von Verweisen von
  ausserhalb des Kreises (1.4.4) gibt es nicht.
- **Der Circle Lead** bleibt, wie ihn die Verfassung definiert:
  Governance fügt ihm keine Accountabilities oder Domains hinzu (sie
  gälten für den Circle Lead jedes Kreises).
- **Mails** lassen sich nicht einzeln abbestellen, nur auf alle Kreise
  ausweiten. Filtere sie im Mailprogramm.

## Bis zur Umstellung

GlassFrog bleibt massgebend, bis wir umstellen: jede Nacht übernimmt das
Tool Struktur, Besetzung und Vorschläge aus GlassFrog und überschreibt
dabei, was hier an diesen Daten geändert wurde.
